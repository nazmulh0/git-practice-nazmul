# Project Documentation & Architecture Guide

## 1. Project Overview
This repository provides a modular, maintainable Python utility and arithmetic project built as part of the Ostad Git & GitHub Practical Assignment.

## 2. Repository Structure
- `README.md`: High-level project summary, student info, badges, and quick-start instructions.
- `.gitignore`: Configured to ignore Python bytecode, cache folders (`__pycache__`), virtual environments, and OS metadata files.
- `src/main.py`: Main executable script displaying student details, execution timestamp, and sample calculations.
- `src/utils.py`: Modular calculation helper module containing pure math operations (`add`, `subtract`, `multiply`, `divide`).
- `docs/project-description.md`: Detailed documentation of the project architecture, modules, and Git branch workflows.

## 3. Implemented Modules
- **Basic Functions**:
  - `add(a, b)`: Returns sum of two numbers.
  - `subtract(a, b)`: Returns difference of two numbers.
- **Advanced Operations**:
  - `multiply(a, b)`: Returns product of two numbers.
  - `divide(a, b)`: Returns division of two numbers with basic divide-by-zero check.
